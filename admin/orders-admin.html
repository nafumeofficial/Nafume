NAFUME — Orders & Tracking Admin

⚠️ Local demo admin only. Do not use as a production admin panel. This page reads and edits orders stored in this browser's localStorage only. It is NOT secure, has NO login, and does NOT connect to Shiprocket. Replace it with a real, authenticated server dashboard before going live.
🔒 No Shiprocket credentials are used or stored here. To attach a courier, paste the AWB / courier / tracking URL you received from Shiprocket (or your courier) and save. The customer's Track Order page will then reflect it. For live auto-tracking, a backend is required — see docs/shiprocket-tracking-setup.md.
